`veri` is the official command-line tool. It ships with the Python SDK; one install gets you both.

By the end of this page you'll have the CLI installed, an authenticated session, and a map of every command group.

## Install

<CodeGroup>
```bash uv (recommended)
uv tool install veri-sdk
```

```bash pipx
pipx install veri-sdk
```

```bash pip
pip install veri-sdk
```
</CodeGroup>

Verify:

```bash
veri version
```

## Log in

Pick the flow that fits your environment.

<CodeGroup>
```bash Browser (default)
veri login
```

```bash Paste a key
veri login --paste
```

```bash Headless / CI
veri login --token vk_your_api_key
```

```bash Custom API URL
veri login --token vk_... --url https://api.veri.studio
```
</CodeGroup>

On a machine without a browser (an SSH session), `veri login --no-browser` skips opening one and goes straight to the paste prompt. `--timeout` sets how many seconds the browser flow waits for you to authorize (default 300) before it falls back to pasting.

Confirm:

```bash
veri whoami
veri doctor
```

`veri whoami` shows the account it resolves to (user and email), the active workspace (name, id, personal or team), the active key, config file path, and that workspace's credit balance. `veri doctor` runs a health check against the control plane.

<Note>
  Credentials live at `~/.config/veri/config.toml` on Linux (or `$XDG_CONFIG_HOME/veri/config.toml`) and `~/Library/Application Support/veri/config.toml` on macOS. `veri whoami` prints the active path. The CLI auto-migrates the legacy `~/.veri/credentials.json` file the first time it runs without a config file, unless `VERI_CONFIG_PATH` or `XDG_CONFIG_HOME` is set. Env vars take precedence over the file.
</Note>

## Command groups

| Group | Pages | Quick description |
| --- | --- | --- |
| `veri run` | [Run](/cli/run) | Submit a workflow from a TOML config + a Python module |

| `veri api-keys` | [Reference](/cli/reference#api-keys) | Create, list, revoke API keys and model access keys |
| `veri secrets` | [Reference](/cli/reference#secrets) | Workspace secrets for agent sessions |
| `veri wandb` | [Reference](/cli/reference#wandb) | Weights & Biases key and default project |

## Global flags

These flags are spliced into every command group by Veri's Typer wrapper:

| Flag | Effect |
| --- | --- |
| `-o`, `--format` | Output format: `table` (default), `json`, `jsonl`, `csv` |
| `--json` | Alias for `--format json` |
| `-q`, `--quiet` | Pipe-friendly: suppress banners and non-essential stdout |

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success |
| `1` | User error (bad arguments, missing files) |
| `2` | API error from the control plane (4xx/5xx) |
| `4` | Auth error (missing/expired key) |
| `130` | Interrupted by SIGINT |
