GCP offers genuine single-GPU A100 VMs, the main reason to pick it over AWS, where the big cards only come as whole 8-GPU nodes.

GCP serving is wired but currently feature-gated: a `provider="gcp"` create returns `400` with `Serving provider 'gcp' is not currently enabled.` until the gate lifts.

## Serving shapes

| `gpu_type` | Memory | GPUs per node | Status |
| --- | --- | --- | --- |
| `A100-80GB` | 80 GB | 1 | Coming soon |

Single H100 VMs on GCP are Spot-only (preemptible), so they are not offered for serving. To serve on H100, use AWS.

## Creating a deployment

```python
client.deployments.create(
    model="Qwen/Qwen2.5-7B-Instruct",
    source="huggingface",
    name="my-deploy",
    gpu={"gpu_type": "A100-80GB", "gpu_count": 1},
    provider="gcp",
)
```

Serving runs on on-demand VMs (not the Spot capacity used for GCP training).
