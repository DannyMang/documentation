A [harness-in-the-loop](/training/harness) variant of the [URL-extraction demo](/demos/harness-url-extraction-agent): the same ReAct task loop, expressed with LangChain's `ChatOpenAI` and message types. `langchain-openai` reads `OPENAI_BASE_URL` / `OPENAI_API_KEY` from the environment, so during training your agent lands on the in-training policy with **no code changes** — the rollout injects those env vars, plus `VERI_TASK_INPUT` and `VERI_POLICY_MODEL`.

## The harness

`agent_langchain.py`:

```python agent_langchain.py
import json
import os
import re
import urllib.request

from langchain_core.messages import AIMessage, HumanMessage, SystemMessage
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model=os.environ.get("VERI_POLICY_MODEL", "Qwen/Qwen3-4B"),
    temperature=0.7,
    max_tokens=512,
)  # reads OPENAI_BASE_URL / OPENAI_API_KEY from the env
MAX_TURNS = int(os.environ.get("VERI_MAX_TURNS", "8"))

SYSTEM = (
    "You find GitHub repository URLs for arXiv papers. On each turn reply with "
    "EXACTLY ONE of:\n"
    "  FETCH: <arxiv_id>   to read the paper's abstract page (e.g. FETCH: 2305.10601)\n"
    "  ANSWER: <url>       when you know the GitHub URL\n"
    "No other text."
)

def fetch_arxiv(arxiv_id: str) -> str:
    url = f"https://arxiv.org/abs/{arxiv_id.strip()}"
    req = urllib.request.Request(url, headers={"User-Agent": "veri-demo-agent/1.0"})
    with urllib.request.urlopen(req, timeout=30) as resp:
        html = resp.read().decode("utf-8", errors="replace")
    text = re.sub(r"<[^>]+>", " ", html)
    return re.sub(r"\s+", " ", text)[:3000]

task = json.loads(os.environ["VERI_TASK_INPUT"])
messages = [SystemMessage(content=SYSTEM), HumanMessage(content=task)]
for turn in range(MAX_TURNS):
    content = (llm.invoke(messages).content or "").strip()
    messages.append(AIMessage(content=content))
    if content.upper().startswith("ANSWER:"):
        break
    match = re.match(r"(?i)^FETCH:\s*(\S+)", content)
    observation = fetch_arxiv(match.group(1)) if match else "Reply with FETCH: <arxiv_id> or ANSWER: <url>."
    messages.append(HumanMessage(content=f"OBSERVATION:\n{observation}"))
```

```text requirements.txt
openai>=1.0
anthropic>=0.40
langchain-openai>=0.2
```

## Run it

Everything else is identical to the [main demo](/demos/harness-url-extraction-agent) — same dataset, same reward, same job. Only the entrypoint changes:

```bash
veri run-harness ./harness \
  --entrypoint "python agent_langchain.py" \
  --base-model Qwen/Qwen3-4B \
  --dataset-id <dataset id> --reward-id <reward id> \
  --gpu-type L4-24GB --gpu-count 1 \
  --rollouts-per-prompt 8 --max-steps 20 \
  --requirements ./harness/requirements.txt
```

Smoke it locally first (no GPU credit) against any OpenAI-compatible endpoint:

```bash
python smoke_local.py --protocol langchain --base-url <endpoint> --model <name> --api-key <key>
```

The LangChain variant trains over the same verified OpenAI route as the default — `ChatOpenAI` speaks the OpenAI protocol under the hood, so token-id capture works exactly like the main demo.
